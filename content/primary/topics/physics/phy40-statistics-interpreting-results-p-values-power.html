the null hypothesis

'there is no difference between study groups with respect to the variable of interest.'

  • p-value <0.05 = significant, <0.01 = highly significant → i.e. an altered result occurs by chance <1% of the time.
  • nowadays, with computers, p-values should be quoted precisely rather than just as 'statistically significant'.
  • something can be statistically significant but not clinically significant.
  • confidence intervals should always be quoted alongside p-values.

Study power - 2x2 table of truth vs test result

Null hypothesis is True | Null hypothesis is False

p-value<0.05 (Yes) | Type I error (alpha) | correct

p-value<0.05 (No) | correct | Type II error (beta)

  • Type I error → 'found a difference when there is no real difference' - occurs by random chance → reduced by lowering the p-value threshold.
  • Type II error → 'missed a real difference' - often due to an inadequate sample size.

power of a test = (1-beta) x 100% (the probability of avoiding a type II error); for publication, power may need to be >80%.

power calculations should be done before a study, to decide on the minimum clinically significant difference (from pilot data or previous research), which is then used to define the control mean + SD needed.

Multiple comparisons

  • increases the type I error rate (the chance of finding a false positive in 20 samples at p=0.05 is 1 in 20).
  • for multiple t-tests, apply Bonferroni's correction, where the significant p-value threshold becomes p<0.05/n (n=number of comparisons).
  • or use ANOVA with post-hoc testing if p<0.01.

One vs two-tailed tests

*'one-tailed' → only interested in whether one mean is greater than the other → usually inappropriate.

*'two-tailed' → either group may have the higher mean.

A result can appear opposite to expectation even with a genuine significant difference, due to chance - so you need good reason/certainty to accept an unexpected result if it seems unlikely or wasn't hypothesised in advance.
