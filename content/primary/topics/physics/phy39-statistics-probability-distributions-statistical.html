Any normal distribution can be converted to a z-score: z = (xi - mean)/SD (datum value, original mean, original SD) - i.e. no. of SDs away from the mean.

  • the standard normal distribution ⇒ mean=0 & SD=1 (the 'z distribution')
  • standard deviation vs SEM (standard error of the mean): SEM = SD/sqrt(n)
  • SD is ALWAYS used when describing the variability of the actual sample data
  • SEM is used to describe the precision of the sample mean (how far it is likely to be from the population mean)

95% population mean = sample mean ± 2 SEM

skewness

Symmetry of the curve (positive/neutral/negative skew)

  • kurtosis = peakedness of the curve: positive = sharper peak and longer tail; negative = wide, flattened distribution.

*positive skew → mean is shifted to the right → the median becomes the correct measure of central tendency, as data is not normally distributed.

  • either accept this and use non-parametric statistical analysis,
  • or transform the data to a normal distribution (e.g. logarithmic, square root, or reciprocal transformation)

Probability and Statistical tests

  • probability theory: we assume sample data is 'typical' of the population data.
  • probability = the relative frequency that an event occurs in an infinite number of trials.

mutually exclusive events: P(A&B)=0 // P(A or B) = P(A)+P(B)

not mutually exclusive (independent) events: P(A&B) = P(A)xP(B) // P(A or B) = P(A)+P(B)-P(A&B)

  • the binomial distribution - describes any situation with a trial that has 2 mutually exclusive, independent outcomes.

mean = np; SD = sqrt(np(1-p))

Statistical inference

One group of interval data - estimating the population mean from sample data.

  • Central limit theorem → repeating an experiment on samples gives a series of sample means; SD of this = SD/sqrt(n) (i.e. the SEM), and the mean of this series = the population mean, following a normal distribution.

Sample mean estimate: xbar - 1.96x(SD/sqrt(n)) <= population mean <= xbar + 1.96x(SD/sqrt(n))

One-sample t-test

  • t-value (akin to a z-value): t = (xbar - mu)/SEM. t=1.96 in large samples → corresponds to p=0.05.
  • the t-distribution is used instead of the z-distribution if the population SD is unknown (values are instead substituted from the sample data).

Non-parametric equivalent

Wilcoxon signed-rank test (one-sample/paired); the Wilcoxon rank-sum test is the Mann-Whitney U test for two independent groups

  • the sample median is compared against a known/hypothetical population median in a non-parametric distribution.
  • each datum is assigned a rank depending on how far it is from the median; values below the median = negative, above = positive; these are summed to give the W-value.

*if the null hypothesis is true, W=0.

'Paired'

Measurements from the same individual/sample. 'Unpaired' = measurements from two different groups (whether or not from the same overall sample).

Two groups of interval data

Key questions: are the data normally distributed? are they paired?

  • unpaired (independent) & normally distributed → Student's unpaired two-sample t-test.

aim: calculate the difference between the two sample means, the standard error of this difference, and a CI for the difference.

SDs of the two groups must be similar → if not, use Welch's correction.

  • paired & normally distributed interval data → Student's paired two-sample t-test.

A 'crossover' study is one where subjects receive both interventions under investigation → each subject acts as their own control.

Non-parametric interval data

  • analogous test to the unpaired t-test = Mann-Whitney U test
  • analogous test to the paired t-test = Wilcoxon matched pairs test

Three groups of interval data

  • ANOVA (analysis of variance) → tells you 'the groups are different' (unmatched groups); post-hoc tests needed to identify which. Uses Student's unpaired two-sample t-tests between pairs of study groups.
  • if 3 groups are matched & normally distributed → repeated measures ANOVA
  • if unmatched but non-parametric → Kruskal-Wallis test
  • if matched but non-parametric → Friedman test.

Categorical data

  • Unpaired, 2 or more groups: Fisher's exact test (2x2 table). Paired, 2 groups: McNemar's test.
  • 3 or more groups: chi-squared (x^2) test - larger tables, or a 2x2 table with Yates' correction (less accurate than Fisher's exact test for a 2x2 table).

Both relative risk and odds ratio can be defined from a 2x2 table: (A/(A+B)) / (C/(C+D))

  • if a prospective study → both relative risk and odds ratio can be calculated.
  • if a retrospective study → only odds ratio can be calculated, as you start with the outcome and the number of patients at risk is unknown.

The 2x2 contingency table

Degrees of freedom = (number of rows - 1) x (number of columns - 1); for a 2x2 table this = 1.

Convention: lower row = control group; columns = outcomes. Cells don't have to be mutually exclusive but should contain a frequency. Observations must all be independent!
