Interscalene block → ~100% phrenic nerve block ∴ only used unilaterally; ~25% stellate ganglion block → Horner's syndrome; ~10% RLN palsy.

(the intercostobrachial nerve (T2) is NOT blocked by an axillary block - it needs separate subcutaneous infiltration over the medial upper arm, otherwise it causes tourniquet pain)

Spinal needles ideally

Length (50→90→152mm) // size (22→25/27→27G) // stylet - prevents tissue 'coring' // 18/19G introducers // minimal trauma // good tactile feedback // doesn't kink or break // clear hub // quick backflow of CSF.

Introducers = 36-38mm. Sprotte tip design > cutting tip design for reducing PDPH. *Stylet should always be used.

Quincke → short bevel cutting tip; ↑gauge

↓PDPH; smaller hole if inserted parallel to the dural fibres → orientate bevel pointing lateral

  • Sprotte → 'pencil point' atraumatic tip → separates & spreads tissue rather than cutting → has a side opening → theoretical concern re: needle tip being further into the CSF space than the visible hub suggests (infection risk)
  • Spinal catheter → 28G → 3-4cm left in the subarachnoid space, can stay in for 2-3 days; leaking catheters preferred over non-leaking (lower pressure risk)
  • CSE (combined spinal-epidural) = a Sprotte spinal needle passed through an epidural needle (16/18G)
  • Loss of resistance devices → a specific low-resistance syringe (not a normal syringe) is used; a spring-loaded syringe can also be used (?) [device names uncertain]
  • Epidural filter → hydrophilic, 0.22 micron mesh, connected via a luer lock → priming volume = 0.5-0.7mls. Transparent & flat. 96hr use before needing replacement.
  • Epidural catheter → polyamide/nylon or teflon, ~90cm long, 16G, ~1mm external diameter & ~0.5mm internal diameter. Must be labelled!
  • has three lateral eyes with a rounded tip, within 2.5cm of the tip ∴ minimum 3cm should be inserted.
  • depth markings: single mark @ distal tip; 5 marks between 5-9cm; double mark @10cm; triple @15cm; quadruple @20cm.
  • problems: retained tip (usually managed conservatively), kinking/looping (especially if excess catheter threaded), and issues with the LR position or original insertion site on removal.
  • CSE needles → Tuohy needle with a pencil point spinal needle → better with a locking mechanism before drug administration.

Peripheral nerve blocks

An important angle/trajectory, triggered by short stimuli; A-delta/C fibres = longer latency responses

N.B. aim for a twitch at ~0.3-0.5mA = appropriate proximity; 1-2mA = still too far (advance); ≤0.2mA = likely intraneural (withdraw needle)

  • Nerve stimulator → 0-5mA current, 0.05-1ms pulse duration, 1-3Hz; -ve cathode attached to the needle & +ve anode to the skin.
  • Nerve mapping → atraumatic needle, 3mm insulated tip, duration 1ms @ 5mA, used to locate a superficial nerve & guide needle puncture site.
  • Needles → short & blunt bevel, insulated with Teflon (except at the tip) → increases current density @ tip; typically 22G, 50/100/150mm lengths.

Typical needle lengths

Interscalene 25-50mm / axillary 35-50mm / femoral 50mm / psoas 80-100mm / sciatic 80-120mm

  • Stimulating catheter → insulated with a wire running to the tip → requires an increased threshold current.

Ultrasound → piezoelectric effect → a varied voltage produces sound at a varied frequency; returning sound waves generate a voltage (send & receive).

*footprint probe used for children or superficial blocks. Thickness of the piezoelectric element determines the resonant frequency; thickness = half wavelength.

Note

N.B. ankle block → covers the peroneal, sural, saphenous & tibial nerves. This is the only block area where a nerve stimulator can be used for a purely sensory nerve, since it also has a motor component beyond the block site.
