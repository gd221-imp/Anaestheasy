Data & correlation

  • 3 key terms: parameter = fixed measurable characteristic of a population; variable = measurable characteristic of a sample, can be independent or dependent; sample statistic = mathematical quantity calculated from variables of a sample to approximate a parameter of the population.
  • data can be converted to categorical → displayed as histograms, tables, scatterplots.
  • 2 types of data:
  1. Interval (continuous) (quantitative) → integer or non-integer data
  2. Categorical (discrete) (qualitative) → nominal or ordinal (ranking) - ordinal is 'pseudo-quantitative' e.g. a pain score

Relationships between two variables

*Correlation → linear correlation, can be judged 'from eyeballing' a scatterplot; r ranges -1 to +1; r^2 ranges 0 to 1 and, as a %, represents the variance explained.

  • if both data sets are normally distributed = use Pearson correlation coefficient
  • if not = use Spearman/Kendall correlation coefficient

(-1 = perfect negative correlation, +1 = perfect positive correlation, r=0 → no correlation)

*Linear regression → if there is a statistically significant correlation, linear regression analysis gives an equation for the straight-line relationship, +95% CI

*Bland-Altman plots → used for comparing two methods of measuring the same variable.

  • scatterplot of mean result (x-axis) vs difference in result (y-axis)
  • mean of the differences being away from 0 = a discrepancy, i.e. bias.
  • 95% CI = 2x SD of the difference distribution.

Central tendency & spread of data

  • central tendency:
  • the mode = most frequent value; best method for nominal categorical values (not affected by outliers - the mean is the outlier-sensitive measure)
  • the median = the central datum when values are placed in order; used for ordinal categorical & interval data (preferred to the mean if data is not normally distributed)
  • the mean = arithmetic mean = total/n; used for interval data only when normally distributed (use in ordinal data is controversial)
  • spread:
  • range = highest minus lowest value
  • percentiles ⇒ interquartile range used for non-normally distributed data → displayed as a box & whisker plot (midline = median)
  • normal distribution ⇒ Gaussian distribution (a parametric distribution)

N.B. if in doubt whether data is normally distributed, it is safer to use non-parametric analysis. A normal distribution is unimodal, symmetrical, bell-shaped when interval data are plotted on a histogram.

N.B. the sample itself doesn't need to be normally distributed, but should be drawn from a population that is.

  • statistical tests for normality: Shapiro-Wilk, D'Agostino-Pearson omnibus test (these can give false positives, and are less accurate with increasing n)
  • a normal distribution is completely described by mean + SD → centre = zenith ⇒ mean = mode = median
  • SD = square root of the sum of the squares of each datum's difference from the mean, divided appropriately

SD = sqrt(sum((xi-mean)^2)/(n-1))

68% of data ± 1 SD; 95% ± 2 SD (95% CI); 99.7% ± 3 SD

sample variance = SD^2; standard error of the mean = SD/sqrt(n)
