Anatomy: subclavian artery → axillary artery → brachial artery → radial / ulnar / common interosseous arteries.

Venous drainage

Cephalic / basilic / median cubital veins → superficial veins. Paired forearm/brachial veins → deep veins. Brachial + basilic veins → axillary vein (@ 1st rib) → subclavian vein.

Note

N.B. AV fistula → radial/brachial artery → cephalic vein.

  • Supraclavicular block, or axillary block only if radio-cephalic.
