Baroreceptor reflex: heart/aorta/carotid sinus → ↓vessel wall stretch → ↓baroreceptor firing rate → negative feedback mechanism.

  • Afferents: CN X (heart/aorta), CN IX - Hering's branch (carotid sinus)
  • Vasomotor centre = ventrolateral medulla
  • Sympathetic tone set by pressor vs depressor centres in the medulla → Cushing reflex (↑BP, ↓HR)
  • Nucleus tractus solitarius connects the sensory nucleus to the vasomotor centre
  • Bainbridge reflex → ↑HR with ↑RA pressure
  • Pre-ganglionic nerve: short, myelinated (B fibres), uses ACh → paravertebral chain → long post-ganglionic nerve, unmyelinated (C fibres), uses NA
  • Central chemoreceptors also contribute: ↓O2, ↑CO2, ↓pH → ↑BP
  • Volume receptors in RA & great veins (?); osmoreceptor → 1-2% change triggers response; volume receptor → 8-10% change; lung/liver act as reservoirs

Haemorrhage classification

  • Class I: ≤15% loss, HR <100, anxiety
  • Class II: 15-30%, HR >100, ↑RR, narrowed pulse pressure, UO <0.5ml/kg/hr, vasoconstriction, fluid mobilisation from interstitium
  • Class III: 30-40%, HR ↑↑, ↓SBP, ↓consciousness, UO <0.5ml/kg/hr, thirst
  • Class IV: >40%, weak pulse, ↓↓SBP, CRT >5sec, no UO, ↑ADH

Management

Give 1L saline → (1) ↑BP → thirst → vasodilatation → BP returns to normal (2) fluid redistribution (3) ↓ADH → diuresis. Give 1L Dextrose 5% → only ~85ml stays in the IVF space (it distributes through total body water), so 4L → only ~330ml.

Body fluid compartments

ICF 66%, ECF 33% → of ECF, 75% ISF, 25% IVF.
