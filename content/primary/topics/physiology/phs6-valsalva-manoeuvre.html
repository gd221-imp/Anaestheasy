Definition

↑intrathoracic pressure via forced expiration against a closed glottis.

Phases

  • Phase I (onset of strain): transient ↑venous return → ↑SV → ↑BP, ↓HR
  • Phase II (continued strain): ↓venous return → ↓CO → ↓BP → ↓stretch → ↓baroreceptor firing → ↑sympathetic tone → ↑HR, ↑SVR, partial BP recovery
  • Phase III (strain release): transient ↓venous return, ↓BP (great vessels expand)
  • Phase IV (overshoot): venous return normalises → ↑CO against still-elevated SVR → BP overshoot → ↑baroreceptor firing → ↓HR

Valsalva ratio

Max HR (phase II) / min HR (phase IV), or longest R-R (phase IV) / shortest R-R (phase II); ratio ↓ with age. Valsalva ratio >1.21 normal; <1.2 abnormal (age-dependent cut-offs).
