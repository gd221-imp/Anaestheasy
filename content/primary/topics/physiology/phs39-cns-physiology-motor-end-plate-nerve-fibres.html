Nernst equation

E = (RT/zF) x ln([ion outside]/[ion inside]), where R = universal gas constant, T = absolute temperature, z = valency, F = Faraday's constant. ↑H+ outside = more negative E.

Transmission at the motor end plate

ACh acting on presynaptic receptors also increases further ACh release. Synaptic cleft ≈ 20nm.

ACh synthesis: choline (recycled & from diet) + acetyl CoA (from mitochondria) → ACh (via choline acetyltransferase, ChAT); hydrolysed by acetylcholinesterase, which is bound to connective tissue within the cleft.

Each action potential releases a large number of ACh vesicles from the motor nerve terminal.

Motor unit = the number of muscle fibres controlled by one motor neurone; a lower ratio allows finer movements.

Nerve fibre classification

  • Aα: motor, 12-20μm diameter, 70-120m/s conduction, myelinated → includes Ia/b proprioceptive afferents
  • Aβ: touch, pressure, proprioception, 5-12μm, 30-70m/s, myelinated → type II afferents
  • Aγ: motor to muscle spindles, 3-6μm, 15-30m/s, myelinated
  • Aδ: pain, cold, temperature, touch, 2-5μm, 12-30m/s, myelinated → type III afferents
  • B: preganglionic autonomic, <3μm, 3-14m/s, lightly myelinated
  • C (dorsal root): pain, warm/cold temperature, touch, 0.4-1.2μm, 0.5-2m/s, unmyelinated → type IV afferents
  • C (sympathetic): postganglionic autonomic, 0.3-1.3μm, 0.7-2.3m/s, unmyelinated

Mixed nerve = multiple neurone/fibre types within one epineurium.

Spinal tracts

  • Ascending, ipsilateral: dorsal columns (fasciculus cuneatus & gracilis)
  • Ascending, contralateral: lateral spinothalamic, anterior spinothalamic tracts
  • Spinocerebellar tracts: dorsal (posterior) spinocerebellar is ipsilateral; ventral (anterior) crosses twice so ends up ipsilateral at the cerebellum
  • Descending, ipsilateral (extrapyramidal): rubrospinal, tectospinal, vestibulospinal tracts
  • Descending, contralateral (pyramidal): lateral corticospinal tract

PNS

GIT innervation is via preganglionic vagal fibres.
