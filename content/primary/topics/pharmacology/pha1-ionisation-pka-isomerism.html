Ionisation

Definition

Hydrophilic properties → more soluble → hydrocarbons require a functional group to ↑hydrophilicity; ↑chain length = ↓hydrophilic

Ionisation → dissociation into ions → strong electrolytes (e.g. NaCl) dissociate fully / weak electrolytes dissociate fractionally

  • Phenol & keto groups often ionise outside of pH 6.5-8.5 (?)
  • Carboxyl & amine groups help dissociation - diagram shows aspirin (carboxyl + keto groups) and morphine (phenol/amine groups)
  • Both carboxyl groups dissociate depending on pH → pKa = the pH at which 50% dissociation is maintained
  • Induction & analgesic agents are all weak acids/bases apart from volatiles
  • pKa of anaesthetics - Henderson-Hasselbalch equation → pH = pKa + log(H+ acceptor/H+ donor)
  • weak base → pH = pKa + log(B/BH+)
  • weak acid → pH = pKa + log(A-/AH)
  • e.g. H2CO3 ⇌ HCO3- + H+ → pH = pKa + log(HCO3-/H2CO3) → pKa of this system = 6.1 (?)
  • [illegible - small formulaic aside next to this: "N.B. log10(N)=p, b^p=N ∴ pH-pKa=log(x), 1=log(x)/10=10.1" - working not fully legible, worth checking against source]
  • if pKa >2 from pH = <1:1 (?) ionised/unionised ratio
  • BASES are ionised BELOW pKa, whereas ACIDS are ionised ABOVE pKa
  • 2 properties needed for an anaesthetic agent to reach the brain = (1) lipid solubility (2) pKa
  • ↑lipid solubility = ↓hydrophilicity ∴ propofol → given as a lipid emulsion
  • 3 properties for ↑onset of action = pKa / lipid solubility / protein binding
  • ↑ionisation = ↑effective concentration away from lipid stores
  • Buffer systems: HCO3-, NH3-, PO4- ('less is more')
  • NMB (neuromuscular blockers) → contain 2x NH4+ groups = ↓lipid solubility

Isomers

A chemical compound with the same molecular formula but a different arrangement of atoms (structural formula)

  1. Structural isomers → same quantity of each atom but different arrangement - e.g. isoflurane & enflurane
  • Tautomerisation = dynamic structural isomerism in equilibrium
  • Aromatic isomers → chemical group is bonded to a different position on the benzene ring
  1. Stereoisomerism → same molecular formula, same structural connectivity, different spatial arrangement

a) Geometric isomerism = cis vs TRANS, & conformers

b) Optical isomerism = mirror image but not superimposable (4 different groups attached to one atom) [N.B. chiral centre = 4 different groups]

  • Enantiomers (mirror images) = dextrorotatory and levorotatory → equal mixture = racemic mixture
  • Diastereoisomers = >1 chiral centre, & not mirror images

Cis-atracurium > atracurium (potency note, referring to cis isomer)
