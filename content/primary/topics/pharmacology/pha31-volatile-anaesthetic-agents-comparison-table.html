The Volatile Comparisons

Table comparing Sevoflurane, Desflurane, Isoflurane, Enflurane, Halothane, N2O and Xenon (with O2 for reference)

MAC (%)

Sevoflurane 2.0 (1.8-2.05 depending on source) / Desflurane 6.6 / Isoflurane 1.17 / Enflurane 1.68 / Halothane 0.75 / N2O 105 / Xenon 71

Oil

Gas partition coefficient: Sevoflurane 47-54 / Desflurane 19 / Isoflurane 91-98 / Enflurane 98 / Halothane 197-224

Blood

Gas partition coefficient: Sevoflurane 0.7 / Desflurane 0.42 / Isoflurane 1.4 / Enflurane 1.8 / Halothane 2.40 / N2O 0.47

Saturated Vapour Pressure (kPa)

Sevoflurane 22.7 / Desflurane 89 / Isoflurane 33 / Enflurane 22.3 / Halothane 32.3

Boiling Point (°C)

Sevoflurane 58.5 / Desflurane 23.5 / Isoflurane 48.5 / Enflurane 56.5 / Halothane 50.2 / N2O -88.5 / Xenon -108

Molecular Weight

Sevoflurane 200 / Desflurane 168 / Isoflurane 185 / Enflurane 185 / Halothane 197 / N2O 44

Metabolism (%)

Sevoflurane 3-5% / Desflurane 0.02% / Isoflurane 0.2% / Enflurane 2% / Halothane 20%

CVS effects

Sevoflurane - ↓SVR, minimal effect on HR; Desflurane - ↑HR/SVR at high concentrations, sympathetic stimulation; Isoflurane - coronary steal risk, ↓SVR; Enflurane - ↓SVR, ↑HR; Halothane - ↓HR, sensitises myocardium to catecholamines/arrhythmias

Resp effects

Sevoflurane - ↓SVR/↑RR; Desflurane - airway irritant, ↑RR, pungent, laryngospasm/coughing risk; Isoflurane - pungent; Enflurane - ↓minute volume, bronchodilator; Halothane - good bronchodilator

Other effects

Sevoflurane - pleasant smell, minimal airway irritation, compound A production with low-flow & soda lime, Baralyme reaction; Desflurane - airway irritant, ↑CBF/ICP (no epileptiform activity); Isoflurane - ↑CBF/ICP (anticonvulsant, no epileptiform activity); Sevoflurane - can cause epileptiform EEG activity at high concentrations/with hyperventilation; Enflurane - ↑CBF/ICP, seizure risk (avoid in epilepsy); Halothane - hepatotoxicity, bradycardia, sensitises to catecholamine-induced arrhythmias; N2O - diffusion into air-filled spaces, PONV; O2 - critical temperature -119°C
