1. Delay cord clamping if possible
  2. Start the clock
  3. Dry/wrap/stimulate/keep warm
  4. Assess colour, tone, breathing, heart rate
  5. Ensure an open airway
  6. 5 inflation breaths, room air, 30cmH2O
  7. Apply PEEP 5-6cmH2O → assess for chest movement
  8. If no response - check position, suction, consider two-person technique/airway adjunct
  9. Repeat inflation breaths; if still no heart rate/HR<60 → start CPR 3:1, IV/IO access, FiO2 1.0
  10. Reassess every 30 seconds → escalate to vascular access and drugs as needed
